# 🌐 Portfolio Website Design

## 🎯 Objetivo

Criar um portfólio moderno, focado em frontend, destacando habilidades visuais, projetos e experiência como desenvolvedor fullstack.

---

## 🧱 Estrutura das Telas

### 1. 🏠 Home (Landing Page)

**Objetivo:** Impacto imediato + apresentação rápida

**Seções:**

* Hero

  * Nome + título: "Fullstack Developer | Frontend Specialist"
  * Pequena descrição (1–2 linhas)
  * Botões: "Ver Projetos" | "Contato"
  * Foto ou ilustração clean

* Tech Stack (rápido)

  * Ícones: React, Next.js, Node, etc

* Destaques

  * 2–3 projetos principais (cards)

* CTA final

  * "Vamos trabalhar juntos"

---

### 2. 👨‍💻 Sobre Mim

**Objetivo:** Humanizar + contar sua história

**Conteúdo:**

* Texto curto (sem enrolação)
* Sua transição / evolução como dev
* Foco atual (frontend)
* Diferenciais (performance, UI, etc)

**Extras visuais:**

* Timeline simples
* Foto ou avatar

---

### 3. 🚀 Projetos

**Objetivo:** Provar habilidade

**Layout:** Grid de cards

**Cada projeto deve ter:**

* Imagem / preview
* Nome
* Descrição curta
* Stack usada
* Botões:

  * Demo
  * GitHub

**Destaque especial:**

* Um projeto maior com layout expandido

---

### 4. 🧠 Skills

**Objetivo:** Mostrar domínio técnico

**Divisão:**

* Frontend
* Backend
* Ferramentas

**Formato:**

* Barras de progresso OU badges
* Evite porcentagens irreais

---

### 5. 💼 Experiência

**Objetivo:** Mostrar profissionalismo

**Formato:** Timeline vertical

**Cada item:**

* Empresa
* Cargo
* Período
* Principais entregas

---

### 6. 📬 Contato

**Objetivo:** Converter visitantes em oportunidades

**Elementos:**

* Formulário simples
* Email
* LinkedIn
* GitHub

---

## 🎨 Design Visual

### Estilo

* Moderno e minimalista
* Muito espaço em branco
* Foco em tipografia e microinterações

### Cores (exemplo)

* Fundo: #0F172A (dark)
* Primária: #6366F1 (roxo/indigo)
* Texto: #E5E7EB
* Destaques: #22C55E

### Tipografia

* Títulos: Inter / Poppins
* Corpo: Inter / Roboto

---

## ⚡ Interações (Diferencial)

* Hover em cards
* Animações suaves (Framer Motion)
* Scroll reveal
* Cursor custom (opcional)

---

## 📱 Responsividade

* Mobile-first
* Menu hamburger
* Cards adaptáveis

---

## 🧩 Extras (Se quiser se destacar)

* Blog técnico
* Dark/Light toggle
* Animação de loading
* Projetos com case study detalhado

## 🧠 Dica estratégica

Seu portfólio precisa parecer um produto frontend de alto nível.
Se o design for comum, você vira "mais um".
Se for polido e bem animado, você já se posiciona acima da média.

## Paleta Principal
🖤 Fundo (Dark base)
#0B0F1A → fundo principal (quase preto com azul)
#0F172A → seções / containers
#111827 → cards

Cores Primárias (gradiente principal)
#6366F1 → Indigo (base da identidade)
#8B5CF6 → Roxo vibrante
#A855F7 → Roxo mais neon

👉 Gradiente usado:

linear-gradient(135deg, #6366F1, #A855F7)

Cores Secundárias (detalhes tech)
#22D3EE → Cyan (ícones / highlights)
#38BDF8 → Azul claro glow
#0EA5E9 → Azul médio

Destaques (ações / sucesso)
#22C55E → Verde (status / CTA secundário)

Texto
#E5E7EB → texto principal
#9CA3AF → texto secundário
#6B7280 → texto mais apagado

Efeitos (ESSENCIAL pra ficar bonito)
Glow roxo:
box-shadow: 0 0 40px rgba(168, 85, 247, 0.4);
Glow azul:
box-shadow: 0 0 30px rgba(56, 189, 248, 0.3);
