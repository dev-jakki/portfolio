# Portfolio Styles

A SCSS library for portfolio websites.

## Installation

```bash
npm install portfolio-styles
```

## Usage

Import the CSS in your project:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/portfolio-styles@1.0.0/dist/portfolio.min.css">
```

Or import SCSS:

```scss
@import '~portfolio-styles/scss/main';
```

## Development

```bash
npm install
npm run build
```

## Structure

- `scss/` - Source SCSS files
- `dist/` - Compiled CSS files
- `abstracts/` - Variables, mixins, functions
- `base/` - Reset, globals, typography
- `layout/` - Layout components
- `components/` - Reusable components
- `pages/` - Page-specific styles
- `themes/` - Theme styles
